# DECKFALL · North Atlantic

穿越火线（CrossFire）风格的浏览器第一人称射击游戏。原生 HTML + Three.js，**无构建步骤、无 npm 依赖**，打开网页即可玩。

**▶ 在线试玩：<https://kylechen-1997.github.io/cf.github.io/>**

> 建议用桌面版 Chrome / Edge / Safari。进入战场后需要点击画面锁定鼠标指针（按 `Esc` 解锁）。

## 玩法

战场是北大西洋蓝小时的真实集装箱货轮甲板，货运甲板行动模式：**先到 40 击杀，或 10 分钟倒计时结束时比分领先**者胜。你从船尾（+z）出生，敌人从船头（-z）基地持续刷出。

- 开局菜单里可以调**敌人数量（1~8）**与**难度（简单 / 普通 / 困难）**；对局中也能用 `+` / `-` 实时增减人数。
- 按住 `Tab` 看战绩面板（左右两列是我方·保卫者与敌方·潜伏者）。
- 被击杀后是 3 秒死亡视角（镜头会自动转向击杀者），然后在你方出生点复活并获得约 1.2 秒无敌。

## 操作

| 按键 | 动作 | 按键 | 动作 |
| --- | --- | --- | --- |
| `W` `A` `S` `D` | 移动（默认奔跑） | `R` | 换弹 |
| `Shift` | 静步潜行（无声） | `1` `2` `3` | 主武器 / 副武器 / 军刀 |
| `Ctrl` | 按住下蹲 | `4` | 投掷物循环（手雷 → 闪光弹 → 烟雾弹） |
| `Space` | 跳跃（支持连跳） | `Q` | 主/副武器快速切换 |
| 鼠标左键 | 开火 | `B` | 背包面板 |
| 鼠标右键 / `V` | 开镜（仅 AWM，两级变倍） | `Tab` | 战绩面板 |
| `+` / `-` | 增减敌人数量 | `Esc` | 解锁鼠标 |

背包切换按 CF 原版规则限制：**只能在出生点安全区内、且本回合尚未开火时**切换（按 `B` 后再按 `1/2/3` 选第几个背包）。

## 特性

- **多武器系统**：AK-47 / M4A1 / AWM / USP / 军刀 / 手雷·闪光弹·烟雾弹三件套，各有独立弹道、射速、后坐与伤害（AK 三枪死、AWM 一枪毙命、爆头一律秒杀）。
- **AWM 两级变倍开镜**，开火强制退镜，带呼吸晃动。
- **程序化士兵骨架**：敌人的走位、据枪、点射、受击、倒地全部是程序化驱动的关节动画（不是静态模型平移），手臂用两骨 IK 按在枪上。敌人 AI 有惯性移动、转身角速度、视线遮挡判定与障碍绕行。
- **双通道视模渲染**：武器与手臂在独立场景里二次绘制，永远不会插进集装箱，开镜时自动隐藏。
- **程序化音效**：枪声、换弹、脚步、爆炸、闪光耳鸣、连杀播报全部由 Web Audio 实时合成，无音频素材文件。
- **程序化贴图**：天空/海浪/集装箱瓦楞/木箱板条，以及每发随机形状的星芒枪口火光。

## 本地运行

需要任意静态服务器（ES Module 与 GLB 不能用 `file://` 打开）：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000/
```

`?debug` 会在 `window.__tactical` 上挂一组调试钩子（切枪、冻结敌人、定格换弹姿势、读取画面状态等）。

## 技术说明

- Three.js 固定在 `0.160.0`，**已本地化到 `vendor/three/`**，由 `index.html` 的 import map 指向本地，不依赖任何 CDN。
- 所有资源路径都是**相对文档**的（`./…`），因此既能本地跑，也能作为 GitHub Pages 的**项目页**（站点根在 `/<仓库名>/`）跑。
- 材质与几何为程序化生成或本地 GLB，无外部资源依赖。
- 更多实现细节与踩过的坑见 [`AGENTS.md`](AGENTS.md)，视觉规范见 [`DESIGN.md`](DESIGN.md)。

## 模型检查

本地服务启动后，打开 `http://localhost:8000/tools/model-preview.html` 可检查人物待机、行走、瞄准和倒地姿态，支持正面 / 侧面切换，无需锁定鼠标。

若需要与仓库原版并排比较，先生成仅本地使用的参考文件（已加入忽略列表）：

```bash
git show origin/main:scripts/enemy_model.js > tools/soldier-before.js
# 打开 http://localhost:8000/tools/model-preview.html?compare
```

运行模型回归检查（无需 npm 依赖）：

```bash
node tools/check-models.mjs
```

检查包含共享几何 / 独立受击材质、五种人物姿态的有限矩阵、双手握点、倒地接地，以及八种武器的换弹手臂姿态。人物本体由 1,056 增至约 16,788 个三角形、60 个网格（不含武器），新增椭球面部、颈部、肩部和手掌形体，以减弱方块感；共享几何仍只创建一次。场景集装箱增加物理角柱与锁杆，木箱使用倒角箱体和四角加固条。

## DECKFALL 视觉方向（2026-09）

项目现在以 **DECKFALL / NORTH ATLANTIC** 为全新入口与场景方向：蓝小时、湿润的深色钢板、低饱和货柜漆面和少量安全橙标线，入口文案与 HUD 也改为货运甲板行动语境。默认枪械使用原厂工业材质，保留可选皮肤但不再以高饱和英雄皮肤作为首屏视觉。

运输船场景补充了吊装龙门吊、悬吊集装箱、货柜角柱与锁杆、木箱加固条、甲板标线和海雾烟囱；人物使用独立的战术装备轮廓、程序化迷彩 / 织物 / 金属表面与第一人称手套。枪械加载时使用物理材质的清漆层、金属度与枪身附件导轨，避免在蓝灰环境中变成一整块黑色。
## GitHub 人物模型调研（2026-09）

已找到并本地评估 [BAMEN · FREE Military Soldier RIGGED](https://sketchfab.com/3d-models/free-military-soldier-rigged-e9c56308a67d4a3db62e914fafa4d198)：约 11.1k 三角面、完整 Mixamo 风格骨骼，仓库镜像为 779 KB 的 GLB。该资源按 CC BY 4.0 使用，项目中保留了 [许可证文本](/Users/handsomechen/workdir/projects/Games/cross_fire/models/bamen_military_soldier.LICENSE.md)，预览页见 [candidate-preview.html](/Users/handsomechen/workdir/projects/Games/cross_fire/tools/candidate-preview.html)。

它的身体比例和装备层次比原始方块模型更自然，但静态版本不含动作剪辑。当前战斗仍由程序化 SoldierRig 驱动，以保证命中部位、双手持枪 IK、走路和倒地逻辑稳定；候选蒙皮模型作为下一步骨骼重定向的本地基准，不会把静态 A 姿直接塞进对局。
